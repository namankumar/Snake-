Snake!
======

A small HTML5 canvas Snake game I built to learn JavaScript and explore the BlackBerry PlayBook. I started with the platform and ended up enjoying game development itself.

Try it
------
Keep snake.html, snake.js, and gameOver.html together. Open snake.html in a browser. There is no build step or package install. The original game uses mouse controls; current browser and touch-device behavior still needs verification.

How the code is divided
-----------------------
Draw handles the canvas. Move tracks the snake's direction. Food handles food generation and eating. Game owns score, pause, resume, and reset. Main starts the game.

Status
------
This is version 1.0, originally aimed at BlackBerry PlayBook 1.0. The original testing used a prelaunch simulator, not a shipping PlayBook. This README update did not retest the game on current browsers.
